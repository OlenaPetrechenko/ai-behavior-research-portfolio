About This Repository
This repository contains my practical work in AI Evaluation and AI Behavior Research.

The projects focus on how Large Language Models understand user intent, ask clarification questions, preserve user requirements, communicate uncertainty, and help users complete real-world tasks.

Each project includes:

research context and objectives;
evaluation criteria;
comparison of LLM responses;
behavioral analysis;
recommendations;
personal reflection.
The purpose of this portfolio is to demonstrate my ability to evaluate AI behavior from a user experience and product perspective.

Project 01 — Comparative Evaluation of LLMs on Travel Planning Tasks
This project compares how ChatGPT, Claude, and Gemini respond to identical travel-planning requests.

The evaluation includes two investigations:

Flight Search
Car Rental
The analysis focuses on user intent understanding, clarification strategy, time to first value, requirement handling, transparency, and task completion.
